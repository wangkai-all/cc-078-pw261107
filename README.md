# 考试数据分析台

导入考生答题、题目与试卷版本后，按题目分析正确率、空答率、选项分布与考生群体差异的纯前端应用。**全部示例数据均为虚构**，考生仅以匿名编号（S-0001…）出现。

## 运行

```bash
npm install        # 如缓存目录无权限：npm install --cache /tmp/npm-cache
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 产物构建（dist/）
npm run preview    # 预览构建产物
node src/engine/engine.test.ts   # 统计引擎自测（44 项）
```

## 功能与对应实现

| 需求 | 实现 |
|---|---|
| 按题目看正确率 / 空答率 / 选项分布 / 群体差异 | 「题目分析」表格 + 点击行打开下钻抽屉（KPI、选项分布图、群体对比图） |
| 点题展开答题记录与卷内位置 | 抽屉内「题目位置与评分规则」表 + 「原始答题记录」表 |
| 筛选可回到原始样本 | 抽屉的记录表即当前筛选口径背后的全部样本，可一键导出 CSV |
| 跨版本改选项 / 评分规则按当时版本计算 | 每题每版本可挂多条规则修订（`RuleRevision.effectiveFrom`），引擎按答题提交时间解析当时规则（示例：Q05 在 B/C 卷增加 E 选项；Q08 在 B 卷 03-05 更正答案 C→A，两个场次分别判定） |
| 补录只更新受影响统计 | `ExamEngine.applyBackfill` 以桶（题目×版本×群体）为粒度做增量加减，返回审计记录（受影响桶清单、顶替数、忽略数），在「数据质量与补录」页展示 |
| 无效 / 缺失 / 重复分开提示，缺项不当作答错 | 三类问题分别检测、分卡展示；无效与重复不计入正确率分母，缺失只提示不记分 |
| 题目筛选 / 版本比较 / 导出审阅表 | 顶部筛选行（版本、群体、知识点、正确率上限、仅看异常）；「版本比较」热力图 + 规则变更清单；「数据与导出」导出审阅表与原始样本 CSV（带 BOM） |

## 数据导入

- **完整数据集 JSON**：`{ questions, paperVersions, candidates, responses }`
- **答题记录 CSV**：`candidateId,paperVersion,questionId,answer,submittedAt[,source]`（answer 空 = 空答，多选用 `|` 分隔）
- **补录 CSV**：同答题记录格式，在「数据质量与补录」页导入，走增量更新通道

## 结构

```
src/engine/    统计引擎（类型、增量统计、示例数据、导入导出、自测）
src/components/ 视图组件（表格、抽屉、图表、版本比较、质量面板、导入导出）
scripts/       jsdom 渲染冒烟测试、截图脚本（需浏览器环境）
```

统计口径：正确率 = 答对 ÷ 有效作答；空答计入有效作答并单独成率；无效答题与重复提交不计入分母；缺失记录不参与任何比率。
